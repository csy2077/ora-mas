ORA-MAS

An open multi-agent harness for robot control, with an agent–code hybrid acceleration pipeline

Siyi Chen, Zhaoning Wang, Yuanbo Yang, Siyuan Bian, Jun Gao · University of Michigan, UC San Diego

A parent agent plans the task and hands each object interaction to a short-lived grasp agent that starts from a fresh context, so no model context grows with the episode. Claude Code then distills successful trajectories into a fixed code workflow, and the hybrid policy calls a model only where the object matters: planning the new scene and making contact.
